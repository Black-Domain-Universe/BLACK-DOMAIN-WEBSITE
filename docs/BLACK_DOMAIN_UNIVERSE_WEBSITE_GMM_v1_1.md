  - **Gallery** - "Museum-grade GNOSIS art & stories."
  - **Playgrounds** - "Steward games, quests, and creative toys for kids & families."
  - **Labs & Tools (optional link into Guide/MP)** - "Behind the scenes: engines, agents, and experiments."

    - Patronage / Marketplace sales

### 5. BLACK DOMAIN GUIDE (ON-SITE AGENT)

**Goal:** One visible agent that helps visitors **navigate, create, and play**.

**Agent Role:**

- Name (working): **Black Domain Guide**.
- **Modes:**
  1. **Story Mode (1D Text):**
     - Prompted micro-stories and lore snippets set in Black Domain / Isra-EL.
  2. **Story + Image Mode (2D Imagery):**
     - Same as above, but also returns safe image prompts or calls image tool (in new UI).
  3. **Site Guide:**
     - "Show me art / games for [age / mood]."
     - "Explain this project in simple terms."

**Constraints:**

- GNOSIS / non-ego tone.
- No pretending to be human.
- No financial or legal advice; only describe offers and flows.
- Kids mode with stricter filters.

UI Placement:

- Floating button on all pages, plus a dedicated **/guide** page explaining capabilities.
